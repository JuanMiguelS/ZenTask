Game Instructions

1.- The objective of the game is to fill the entire grid with the same color.

2.- To do this, select a color and click on any block of the grid.

3.- All adjacent blocks to the selected block will change to the selected color.

4.- You have a limited number of moves to achieve this.

You must complete a task before accessing the game.
